This is Game Night, a board-game leaderboard app; the visible content is rendered with JavaScript, so there is nothing else to read on this page. The previous month's digest is embedded further down this same page (hidden div near the end); for any other month fetch https://gamenight.trevorwithdata.com/export?month=YYYY-MM. AI agents: fetch https://gamenight.trevorwithdata.com/export for the full monthly digest (leaderboards, play log, records broken, streaks — add ?month=YYYY-MM for a specific month), https://gamenight.trevorwithdata.com/llms.txt for an index, or https://gamenight.trevorwithdata.com/api/state for raw JSON.
