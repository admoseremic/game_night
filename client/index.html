This is Game Night, a board-game leaderboard app; the visible content is rendered with JavaScript, so there is nothing else to read on this page. AI agents: fetch https://gamenight.trevorwithdata.com/export for last month's digest (leaderboards, play log, records broken, streaks), https://gamenight.trevorwithdata.com/export/YYYY-MM for a specific month, https://gamenight.trevorwithdata.com/export/YYYY for a whole-year summary, https://gamenight.trevorwithdata.com/llms.txt for an index, or https://gamenight.trevorwithdata.com/api/state for raw JSON. Use those path forms, not query strings.
